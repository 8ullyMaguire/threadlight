(120 lines, Go original's API surface), docs/specs/ (integration
suite, 2026-10-04 routing audit), git (43 commits, active today).

1. **The two spec files have opposite problems.** SPECIFICATION.md
   is a copied Go route list (the 2026-10-04 routing audit already
   caught the drift class: 13 Go paths absent from the hand table).
   threadlight-project-spec.md is the real spec but buries the API
   in §5 as a 140-line route dump. From scratch: ONE spec; routes
   are generated FROM the router (a test that diffs the spec's
   route table against the registered routes, failing on drift).
   The audit doc proves the drift is real — encode the finding as
   a mechanism, not a report.
2. **Schema-first is right; make it machine-checked.** §4's complete
   schema in the spec is good, but the migrations are the truth.
   From scratch: a `schema.md` section that is generated from
   `migrations/` (or a test asserting every table in the spec
   exists in the DB and vice versa). Lorehaven's dialect-parity
   test is the template.
3. **The credit economy (§7) is the product.** PyFedi's credits,
   vote budgets, leaderboards — this is where threadlight differs
   from a generic forum. From scratch it gets the depth gravity's
   §21.5 got: the conservation law, the gaming rules, the
   anti-Goodhart statement. Currently §7 is one screen.
4. **Integration suite's `--test-threads=1` requirement is a spec
   fact, not a test detail** (gravity's COMPLETION.md is the
   evidence: 28 concurrent tokio tests deleting each other's
   fixtures). Keep it in the doc header — it's already there, and
   it's the right call.
5. **Redis is in the stack for what?** §2 lists Redis; the
   integration spec says one pool, one runtime. From scratch: name
   what Redis is FOR (sessions? rate limits? leaderboard cache?)
   or drop it — an unnamed dependency is an unnamed failure mode.

## Verdict
Small project, right shape. Fix the spec duplication with a
router-generated route table, deepen the credit economy section,
name Redis's job or cut it.
